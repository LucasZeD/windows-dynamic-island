# Welcome to your notes

Every note is a Markdown file in this folder, so any editor (Obsidian too) can open it.
Changes are **saved as you type**.

## Writing

- `# Heading`, `**bold**`, `*italic*`, `~~strike~~`, `` `code` ``
- Lists, and tasks you can tick:
  - [ ] Try a task
  - [x] Open this note
- > Quotes

## Links

- Web links: [Markdown guide](https://commonmark.org/help/)
- Other notes: [[Welcome]]: click one that doesn't exist yet and it's created.

## Pictures

Paste a picture (Ctrl+V) and it's saved in `attachments/` and linked here.
Click the link to unfold the picture; click the picture to see it full size.
